SIAR Package Repositories

Install and automatically receive updates for SIAR (Survivable Identity & Autonomous Routing) across Linux distributions and Windows.

🐧 Ubuntu & Debian (APT)

Add the official APT repository to receive automated updates:

# 1. Download official GPG key
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://irshadlab.github.io/siar/KEY.gpg | sudo gpg --dearmor --yes -o /etc/apt/keyrings/siar.gpg
sudo chmod a+r /etc/apt/keyrings/siar.gpg

# 2. Add repository source
echo "deb [signed-by=/etc/apt/keyrings/siar.gpg] https://irshadlab.github.io/siar stable main" | sudo tee /etc/apt/sources.list.d/siar.list

# 3. Update & Install SIAR
sudo apt update
sudo apt install siar

🎩 Fedora & Red Hat (DNF / RPM)

Add the official RPM repository to receive automated updates:

# 1. Add repository configuration
sudo curl -fsSL https://irshadlab.github.io/siar/rpm/siar.repo -o /etc/yum.repos.d/siar.repo

# 2. Install SIAR
sudo dnf install siar

🏹 Arch Linux (AUR)

Install via your preferred AUR helper:

# Precompiled binary (Recommended)
paru -S siar-bin

# Or build from source
paru -S siar-git

🪟 Windows (winget / ZIP)

Install via Windows Package Manager or GitHub release:

# Direct ZIP Download
Available on GitHub Releases

# Or extract and run:
.\siar-desktop.exe
